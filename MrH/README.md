# Обновление меню спавна (3D модели)

## Что добавлено
1. **`SpawnMenu.java`**: Меню переделано в сетку с вкладками (`3D люди`, `2D люди`, `Какашки`, `Комбо`). В каждой клетке иконка и подпись.
2. **Новые 3D модели**: В меню добавлены Нормис, Пупс (`pups.obj`), Полиция (`police.obj`), Коммунист (`com.obj`), Беременная (`berem.obj`), Военный (`ca.obj`).
3. **`Engine.java`**: 
   - Добавлен хелпер `spawnRigged` для удобного спавна скининг-моделей.
   - Конструктор `SpawnMenu` обновлен для передачи текстур 2D-людей.
   - Обработка новых кейсов в `spawnFromMenu`.
4. **`mesh/MrH/rig.txt`**: Добавлены закомментированные строки для индивидуальной подстройки отступа рук для новых моделей, если автоопределение где-то промахнется.

Все файлы нужно заменить. Сборка стандартная (`build.bat`).
